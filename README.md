# AgingResearch.News MCP server

<img src="https://agingresearch.news/logo.png" alt="AgingResearch.News app icon" width="96" height="96">

AgingResearch.News helps researchers find and follow work on aging and age-related disease. It connects biomedical papers with evidence summaries, clinical trials, research grants and related topics.

MCP endpoint: `https://agingresearch.news/api/mcp`

Public research lookups work without an account. Personal features, including followed topics and saved questions, use OAuth.

Documentation: [agingresearch.news/developers#mcp](https://agingresearch.news/developers#mcp)
